# Projeto M1.2 – Melhoria de Imagens Médicas

## Descrição
Este repositório contém a implementação do **Projeto M1.2 – Desenvolvimento de um pipeline de melhoria de imagens médicas utilizando operações pontuais e técnicas de filtragem espacial**.

O trabalho foi desenvolvido em `Python` utilizando o `Google Colab` e aborda o processamento de imagens dermatológicas médicas, incluindo a inserção de ruído Gaussiano, transformação Gamma, filtragem Bilateral e filtragem High-Boost.


## Disciplina:
Processamento de Imagens

## Conteúdo
- Seleção e caracterização das imagens;
- Inserção de Ruído Gaussiano;
- Transformação de Intensidade (Gamma);
- Filtragem Bilateral;
- Filtragem High-Boost;
- Desenvolvimento de diferentes configurações do pipeline;
- Análise visual dos resultados;
- Avaliação utilizando as métricas PSNR e SSIM.
